# Reserveit: Facility Reservations Made Easy

## About the Project

**Reserveit** is a web-based facility reservation system designed to simplify the process of booking facilities, primarily for the NU Laguna and Inspire campuses.

The system allows users to register, log in, browse available facilities, and manage their reservations. It also provides automatic fee computation based on facility type, booking duration, and other predefined rules.

Reserveit aims to prevent double bookings, improve reservation management, and provide a convenient platform for both users and administrators.

## Project Objectives

- Simplify the facility reservation process.
- Prevent double bookings and reservation conflicts.
- Automatically calculate reservation fees.
- Provide secure user registration and authentication.
- Maintain an organized and reliable database.
- Provide a responsive and user-friendly interface.
- Allow administrators to manage reservations and monitor facility usage.

## Features

### User Management
- User registration and login.
- Secure account authentication.
- Profile management.
- Profile photo upload.

### Facility Reservation
- Book facilities for specific dates and times.
- Add, edit, and cancel reservations.
- Prevent overlapping reservations.
- Provide reservation confirmations and conflict alerts.

### Fee Computation
- Automatically calculate reservation fees.
- Determine charges based on facility type and booking duration.
- Display computed fees before reservation confirmation.

### Lost and Found System
- Report lost and found items.
- Provide item descriptions and details.
- Include item images and information about where and when the item was lost or found.

### Administrative Panel
- View and manage reservations.
- Update reservation fee structures.
- Generate reports.
- Monitor facility usage and revenue.

### Responsive User Interface
- User-friendly dashboard.
- Responsive design for desktop and mobile devices.
- Clear notifications, prompts, and alerts.

## Supported Facilities

The system is designed to accommodate reservations for the following facilities:

- Training Gym
- Swimming Pool
- Tennis Court
- Basketball Court
- Multipurpose Gym

## Database Structure

The proposed database includes the following main tables:

| Table | Description |
|---|---|
| `useraccs` | Stores user account information, credentials, and account types. |
| `reservations` | Stores facility bookings, reservation schedules, payment methods, and fees. |
| `lost_and_found` | Stores reports of lost and found items, including descriptions, locations, dates, and images. |
